# Privacy and support scope · AI Companion Lab

HoloKeyboard composes up to 120 display characters locally from keys it receives. The line is kept in memory and is cleared when focus or protection changes, Input is turned off, or Input Lock is enabled. Windows protection metadata is checked to block password and unverified fields; a program that draws its own password box without reporting it may not be recognised, so use Input Lock for secrets. The app does not read the target field or save, copy, log or transmit typing. Physical glow can still reveal pressed keys with Input Lock OFF. Turn it on before typing secrets.

The only persistent preference introduced for supporter styles is a boolean in `%LOCALAPPDATA%\AI Companion Lab\HoloKeyboard\support.json`. The app opens the AI World Portal Ko-fi address in the default browser only on request. The default browser handles the external page. The app does not check payment, require an account or send telemetry.

The candidate targets Windows x64. Compact 57 and Full 104 are included. Exact installed profile availability appears in Help. A supported isolated Win32 Edit verified auto preview/lock. A previous isolated Chrome fixture verified a subset of ordinary fields. App-specific accessibility, live ChatGPT preview, hardware tablet touch, and actual Japanese/Chinese IME practice have incomplete coverage. Some providers fail or time out. Windows IME can supply composition text marked with ◌. A compatible local System.Speech voice is required for audible reading in Typing Practice. Voices are not bundled. Personal story files in `%LOCALAPPDATA%\AI Companion Lab\HoloKeyboard\stories` are only read locally by Typing Practice; their content is never sent anywhere or kept elsewhere.
